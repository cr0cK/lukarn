# D8 — Fall back to the Drive thumbnail when sharp cannot decode

**Confidence.** stated — owner: Alexis Mineaud, pre-pipeline hand-authored store · 2026-08-12

**Context.** The libvips bundled with sharp cannot decode every HEIC file or proprietary
RAW format.

**Decision.** If `transform()` fails, `MediaRenderer` requests the `thumbnailLink`
generated by Google, replaces its `=s220` suffix with the desired size, and runs the
transformation again on this JPEG preview.

**Rejected.** Returning an error or an "unsupported format" image: the file is visible
in Drive, so it must be visible here too. Also rejected: bundling a RAW decoder in the
Docker image.

**Consequences.** A Drive preview is lower quality than a render from the original; it
is better than an empty tile. The fallback is logged at `warn` level.
