# D260812b — The project is called lukarn

**Confidence.** stated — owner: Alexis Mineaud, pre-pipeline hand-authored store · 2026-08-12

**Context.** D260811 named the project **nonni**, Italian for grandparents, and
gave a good reason: the people it was written for. The reason held; the word did
not. Two objections, and neither is a matter of taste alone.

It is too intimate for the surface it sits on. A public repository is read by
strangers, and a name drawn from family life asks them to step into something
that is not theirs — the affection reads as private where a tool should read as
neutral. And it sounds wrong: the doubled _n_, the trailing _i_, a word that has
to be spelled out loud every time it is said.

The moment to correct that is now. Nothing has been published under the name
nonni: no tag, no release, no image in any registry, no clone anywhere but the
machine that wrote it. After the first tag, the name is in every pull command,
in a release page and in whatever copies exist; before it, it is a text
substitution and one volume to migrate.

**Decision.** The project is called **lukarn**.

It is a Gothic word for a lantern — the thing picked up to go and look in the
dark. It is also the word philologists put forward, beside Irish _luacharn_, to
argue that French _lucarne_ descends from Latin _lucerna_; that derivation is
not the accepted one, which runs through Frankish _lūkinna_, "an opening closed
by a flap", but the two readings both land where the application does. A
lantern, or the small roof window that lets light in and lets you see inside:
either is what this does to photos sitting in the dark of someone else's Drive.

It is short, it carries no doubled letter, it ends on a hard consonant, and it
reads the same way to a French and an English speaker. It belongs to a dead
language, so nothing living holds it: no company, no product, no trademark and
no software of that name was found.

**Ruled out: kadre**, from _cadre_ — the photographic gesture itself, and the
most immediately legible of the candidates. An American IT recruiting agency
already trades under it. A different field, but still software.

**Ruled out: skura**, from _camera obscura_ shorn of its prefix. Clear of the
photo world, but a sales-enablement company carries the name, and _skóra_ means
skin in Polish.

**Ruled out: keeping nonni** on the grounds that renaming twice in two days is
undignified. The dignity is in what gets published, not in how the log to it
reads.

**What it costs a running instance.** The session cookie changes name, so
everyone signs in once more; the rows in the database are untouched. The volume,
the database file and the cache take the new name, which is one migration to run
before the first start on this version — the same shape as the one D260811
described, and written down in the same place.

D260811 keeps its own account intact, nonni included: a log names what it
replaced.
